# Pocket Mail

Поштовий застосунок для телефона в стилі Outlook, до якого може підключатися Claude.

- **Застосунок для телефона.** Вхідні, папки, пошук, фільтри «Непрочитані» / «З позначкою»,
  читання HTML-листів (зовнішні картинки заблоковані, поки ви не натиснете «Показати»), вкладення,
  нові листи, відповідь, відповідь усім, пересилання, свайп вправо = архів, свайп вліво = кошик,
  потягнути вниз = оновити, темна тема. Встановлюється на головний екран як звичайний застосунок (PWA).
- **Конектор для Claude (MCP).** Claude може шукати й читати листи, відкривати вкладення,
  відповідати, пересилати, надсилати, позначати, переносити й видаляти листи. Працює з
  claude.ai, мобільним застосунком Claude, Claude Desktop і Claude Code.
- **Будь-яка пошта з IMAP/SMTP.** Gmail, ukr.net, i.ua, meta.ua, Yahoo, iCloud, WP/Onet/Interia/O2
  налаштовуються автоматично; для інших сервер вказується вручну.

```
 Телефон (PWA)  ──HTTPS──►                         ──IMAP──► ваша пошта
                          Pocket Mail сервер (Bun)
 Claude (MCP)   ──HTTPS──►   /api   /mcp           ──SMTP──► відправка
```

Паролі від пошти зберігаються тільки на сервері у файлі `.env`. Телефон і Claude знають лише
ключ доступу `MAIL_APP_TOKEN`.

## Спробувати без пошти (демо)

```bash
cd mail-app
bun install
bun run demo            # відкрийте http://localhost:8787, ключ: demo
```

## Налаштування з вашою поштою

1. Встановіть [Bun](https://bun.sh): `curl -fsSL https://bun.sh/install | bash`
2. Створіть пароль застосунку у своїй пошті (звичайний пароль зазвичай не підійде):
   - **Gmail:** увімкніть двоетапну перевірку, потім https://myaccount.google.com/apppasswords
   - **ukr.net:** Налаштування → «Доступ через поштові програми» → увімкнути IMAP і створити пароль для програм
   - **iCloud:** https://account.apple.com → «Паролі для програм»
   - **Yahoo:** Account security → Generate app password
   - **Outlook.com / Hotmail:** Microsoft вимикає вхід за паролем для IMAP/SMTP в особистих акаунтах,
     тому з ними цей застосунок може не працювати. Для пошти Microsoft у Claude вже є вбудований
     конектор Microsoft 365.
3. Налаштуйте й запустіть:
   ```bash
   cd mail-app
   bun install
   cp .env.example .env
   # впишіть MAIL_USER, MAIL_PASSWORD і ключ доступу:
   echo "MAIL_APP_TOKEN=$(openssl rand -hex 24)" >> .env
   bun start
   ```
4. Відкрийте `http://<IP-комп'ютера>:8787` на телефоні (в тій самій Wi-Fi мережі) і введіть ключ.

## Доступ з будь-якого місця + встановлення на телефон

Щоб застосунок працював поза домашньою мережею і щоб claude.ai міг підключитися, серверу потрібна
публічна HTTPS-адреса. Найпростіше: безкоштовний Cloudflare Tunnel.

```bash
# швидкий тимчасовий URL:
cloudflared tunnel --url http://localhost:8787
# → https://щось-випадкове.trycloudflare.com
```

Для постійної адреси створіть іменований тунель у Cloudflare або розгорніть сервер на VPS / Fly.io /
Railway (є `Dockerfile`; змінні з `.env` задайте як secrets).

**Встановлення на головний екран:**
- **iPhone (Safari):** Поділитися → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Встановити застосунок».

## Підключення Claude

У застосунку: меню (аватар зліва вгорі) → **Підключити Claude**. Там уже готові посилання й
команди з вашою адресою та ключем, з кнопками «Копіювати».

### claude.ai і мобільний застосунок Claude

Settings → Connectors → **Add custom connector**. URL:

```
https://ваш-домен/mcp/<MAIL_APP_TOKEN>
```

Конектор, доданий на claude.ai, одразу доступний і в застосунку Claude на телефоні.

### Claude Code

```bash
claude mcp add --transport http pocket-mail https://ваш-домен/mcp \
  --header "Authorization: Bearer <MAIL_APP_TOKEN>"
```

### Claude Desktop (локально, веб-сервер не потрібен)

`claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "pocket-mail": {
      "command": "bun",
      "args": ["/повний/шлях/до/mail-app/server/mcp-stdio.ts"]
    }
  }
}
```

Налаштування береться з `mail-app/.env`.

### Інструменти, які отримує Claude

| Інструмент | Що робить |
|---|---|
| `list_folders` | папки з кількістю непрочитаних |
| `list_emails` | листи в папці, нові зверху, з фільтром «лише непрочитані» |
| `search_emails` | пошук за темою, відправником, отримувачем, текстом |
| `read_email` | повний лист + список вкладень |
| `get_attachment` | вміст вкладення (текст, картинка або файл) |
| `send_email` | новий лист |
| `reply_to_email` | відповідь (або відповідь усім) з цитатою, у тому ж ланцюжку |
| `forward_email` | переслати разом із вкладеннями |
| `mark_email` | прочитано / непрочитано, позначка |
| `move_email` | перенести в іншу папку |
| `delete_email` | у кошик (з кошика = назавжди) |

`MCP_READ_ONLY=1` залишає Claude тільки читання: інструменти надсилання, переносу й видалення зникають.

Приклади запитів: «Підсумуй непрочитані листи за сьогодні», «Знайди рахунок від Anna і скажи суму
з вкладення», «Відповідай Олені, що зустріч у четвер підтверджую», «Перенеси всі листи від GitHub в архів».

## Безпека

- `MAIL_APP_TOKEN` дає повний доступ до пошти. Мінімум 16 символів, генеруйте через `openssl rand -hex 24`.
  Якщо ключ витік: змініть його в `.env` і перезапустіть сервер.
- Використовуйте тільки HTTPS, коли сервер доступний з інтернету.
- HTML-листи показуються в ізольованому iframe без JavaScript; зовнішні картинки (трекери) заблоковані за замовчуванням.
- Неправильний ключ отримує затримку відповіді, щоб ускладнити перебір.

## Розробка

```bash
bun run dev      # демо-режим з автоперезапуском
bun test         # тести API і MCP-конектора
bunx tsc -p .    # перевірка типів
```

Структура:

```
server/
  index.ts           HTTP-сервер (застосунок + API + /mcp)
  mcp-stdio.ts       MCP через stdio для Claude Desktop / Claude Code
  mcp.ts             інструменти для Claude
  app.ts             маршрути API
  imap-provider.ts   IMAP (imapflow) + SMTP (nodemailer)
  demo-provider.ts   демо-скринька в пам'яті
  compose.ts         відповідь / пересилання
  config.ts          налаштування, автовизначення серверів за доменом
public/              PWA (HTML/CSS/JS без збірки)
test/                тести
```
